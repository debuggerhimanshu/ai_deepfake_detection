## ⚙️ Setup Instructions

### Prerequisites
- Python 3.9 or 3.10
- pip
- A modern web browser (Chrome recommended)

---

### Step 1: Clone / Navigate to Project

```bash
cd deepfake-detector/backend
```

### Step 2: Create Virtual Environment (Recommended)

```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Mac/Linux:
source venv/bin/activate
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

> **Note:** On slower laptops, skip TensorFlow for now. The system works perfectly in mock-prediction mode too.

### Step 4: Generate the Demo ML Model

```bash
python train_mock_model.py
```

This creates `model/audio_model.pkl` — a calibrated Random Forest classifier.

### Step 5: Start the Backend Server

```bash
python app.py
```

You should see:
```
=======================================================
  DeepGuard API Server
  Running on http://127.0.0.1:5000
=======================================================
```

### Step 6: Open the Frontend

Simply open `frontend/index.html` in your browser.

> No build step needed. No npm. Just open the HTML file.

## 🎯 How to Use

1. Open `frontend/index.html` in Chrome
2. Drag & drop a video or audio file (or click to browse)
3. Click **Analyze File**
4. Watch the step-by-step progress animation
5. View the result: **AUTHENTIC** or **DEEPFAKE**
   - See confidence score (%)
   - For video: see frame-by-frame analysis grid (red = suspicious)
   - For audio: see waveform + MFCC frequency chart

### Demo Without Backend
The frontend includes a built-in mock mode — if the backend isn't running, it generates a realistic demo result automatically. Perfect for exhibition!

## 🧠 How It Works (Simple Explanation for Judges)

### Video Detection
```
Video File
    ↓
Sample 12 frames evenly (not all frames — keeps it fast)
    ↓
For each frame:
   → Preprocess image (resize to 224×224, normalize)
   → Pass through CNN model
   → Get suspicion score (0 = real, 1 = fake)
    ↓
Aggregate: Take 80th percentile of scores
    ↓
If score > 55% → DEEPFAKE verdict
```

**Why the 80th percentile?**
Deepfake videos aren't fake in every frame. Often just a few frames show manipulation artifacts. The 80th percentile catches these outlier-suspicious frames better than a simple average.

### Audio Detection
```
Audio File
    ↓
Load at 16kHz sample rate, convert to mono
    ↓
Split into 2-second segments
    ↓
For each segment:
   → Extract 40 MFCC coefficients (vocal fingerprint)
   → Extract spectral flatness (how "robotic" it sounds)
   → Extract zero-crossing rate (signal texture)
    ↓
Feed 84-feature vector into RandomForest classifier
    ↓
If deepfake probability > 55% → DEEPFAKE verdict
```

**What are MFCCs?**
Think of it like a voiceprint. Your voice has a unique "shape" in frequency space. AI-generated voices (from tools like ElevenLabs or Tacotron) have subtly different patterns in their MFCC distributions — the model learns to spot these.

## 🎤 Exhibition Presentation Script

### Opening (30 seconds)
*"Deepfakes are AI-generated fake videos and audio that can make anyone appear to say or do things they never did. They're used for disinformation, fraud, and impersonation. This project demonstrates how AI can be used to fight back — by detecting deepfakes automatically."*

### Demo (2 minutes)
1. Show the dashboard: *"Clean interface — drag and drop a file here."*
2. Upload a video: *"The system samples frames from the video — it doesn't process every frame, just key moments, which keeps it fast."*
3. Watch the progress: *"See these steps — frame extraction, preprocessing, CNN analysis — these are the actual stages happening in the backend."*
4. Show the result: *"Here's the verdict with a confidence score. The frame grid shows you which exact frames triggered the alarm — highlighted in red."*

### Technical Explanation (1 minute)
*"For video, we use a Convolutional Neural Network — the same type of AI used in face recognition. It learns patterns in how deepfake tools distort skin textures, lighting, and facial boundaries that the human eye misses."*

*"For audio, we extract MFCC features — these are like a mathematical fingerprint of someone's voice. A Random Forest classifier then decides if those fingerprints match real or synthetic speech."*

### Closing (30 seconds)
*"Real-world systems like this are used by Facebook, Microsoft, and news organizations. This is a lightweight prototype — a real production system would use larger models trained on millions of examples. But the core concepts are identical."*

## 📦 Tech Stack

| Component | Technology | Purpose |
|-----------|-----------|---------|
| Frontend  | HTML5 + CSS3 + Vanilla JS | Dashboard UI |

## ⚡ Troubleshooting

| Problem | Fix |
|---------|-----|
| `ModuleNotFoundError: librosa` | Run `pip install librosa soundfile` |
| `ModuleNotFoundError: cv2` | Run `pip install opencv-python` |
| Backend not reachable | Make sure `python app.py` is running; check port 5000 |
| CORS error in browser | Already handled by `flask-cors`; check if backend is running |
| Large file rejected | Max 100MB — configured in `app.py` |
